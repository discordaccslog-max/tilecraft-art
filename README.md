# Tilecraft Art

Storefront, pixel art packs and the Tilecraft Studio for Tilecraft Art. The site is static HTML, CSS and vanilla JavaScript, published with GitHub Pages from the root of the `main` branch.

## Everyday edits (no rebuild needed)

- **Start selling a product:** open `js/products.js` and paste the product's checkout link into its `checkoutUrl`. The buy button appears on that product page automatically. Set your checkout to send buyers to the product's `thankYouPath` after payment.
- **Show a support email:** open `js/site-config.js` and fill in `supportEmail`. It then appears on the Contact page and in the footer, and the studio shows "Report a problem" links on assets.

## Administrator key

One administrator key unlocks every pack. Only its SHA-256 fingerprint is stored (in `js/license.js`), so it cannot be recreated from the code. To replace it, run `node build/admin-key.js`: it prints a new key once, updates the fingerprint, and the old key stops working after you deploy.

## Rebuilding

The art, sheets, metadata, Tiled files, zips and HTML pages are all generated by the build script.

```bash
npm install
npm run build      # draws every pack, runs every check, writes the site (about a minute)
npm run verify     # links, placeholder scan, zip contents, keys
npm run preview    # local preview at http://localhost:4173/tilecraft-art/
```

The site is also hosted on Vercel. `npm run deploy:vercel` copies only the built site into `.deploy/tilecraft-art` and deploys it to production (needs the Vercel CLI, signed in). It works at the domain root as well as under a sub-path, because every page uses relative links.

`build/review.js <pack>` writes contact sheets to `.review/` for visual checks.

## How the pieces fit

| Path | What it is |
| --- | --- |
| `build/packs/*.js` | Each pack's art, drawn pixel by pixel in code |
| `build/lib/` | Raster drawing, autotile renderer and seam checks, pack exporter |
| `build/site.js`, `build/content.js` | Page templates and all written content (license, policies, FAQ) |
| `js/` | Site scripts: license keys, pixel renderer, home page, unlock and thank-you pages |
| `studio/` | The Tilecraft Studio progressive web app |
| `assets/packs/<id>/` | Generated sheets, `meta.json` and the downloadable `.zip` for each pack |

## A note on access control

Everything runs in the browser: license keys are generated and checked client-side, and pack files are static files on GitHub Pages. The key system keeps honest buyers' libraries organised; it is not copy protection, and the files are reachable by anyone who knows their URLs.
